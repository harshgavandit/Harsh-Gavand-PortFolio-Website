# Audit follow-through verification

This release is restricted to the portfolio and its AI service. The owner explicitly excluded linked application backends, authentication secrets, hosting changes, and the community application's roadmap. Agri Samaj remains a homepage community contribution.

## Implemented

- Confirmed GlobeTrek shipment: quotation building, invoice generation, and automated email tools, delivered in a full-time role. Removed the unsupported HRP page-load percentage instead of inventing a baseline.
- Distinct flagship accents/composition and a compact 48px mobile assistant control. Text and opt-in voice are preserved.
- Deferred assistant dialog and secondary client routes, with complete static HTML preserved through explicit server page components.
- Capability-aware role evidence; a stack tag alone cannot establish delivered work, duration, or production operations. Narrow output guards reject known source contradictions about post-dispatch refunds.
- Anonymous atomic service counters, failure measurement, latency buckets, and conservative allowance accounting. Public sample-answer caching remains behind shared admission; private/custom inputs are never cached.
- Refreshed 28 allowlisted code files in six public repositories, a weekly freshness check, a repeatable evaluation set, and an enforced release fingerprint gate.

## Evidence boundaries

The initial 24-case/two-repetition benchmark passed 45/48 checks; its report is retained in `initial-evaluation.json`. Two failures identified admission retrieval that surfaced constructor defaults without the atomic Lua enforcement. File intent and mechanism terms now retrieve the enforcement code, with a regression assertion. The remaining failure was a grader false negative: “isn't stated” correctly acknowledged missing salary information. The grader now accepts that explicit wording and still rejects an invented salary in a negative test. Reference-fact checks were retained.

The final report is `evaluation.json`: **48/48 response checks**, **8/8 retrieval checks**, 2,861ms median, 5,134ms p95, 100,454 input tokens, 4,755 output tokens, and $0.024865 conservative allowance accounted. All 48 were fresh provider calls. The runtime/source fingerprint gate passed. Expectations are source-derived and synthetic, not independently human-labelled. Source links and selected facts are checked; this does not certify every possible answer or provide a production accuracy rate. Local benchmark repetitions bypass the answer cache and do not enter production service metrics.
