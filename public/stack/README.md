# Technology logo sources

`technology-logos.svg` is a selected, self-hosted SVG symbol collection used by the portfolio's résumé stack. Visible text labels accompany every decorative mark. Abstract capabilities and tools without a selected brand mark use the site's existing Lucide icon set.

Brand geometry comes from Simple Icons 16.35.0 and the pinned Devicon commit `6a37858047b0e8d9c9c0e68f4a071fc410652e89`. Fill colors inherit the portfolio's monochrome foreground. `sources.json` records each symbol's labels, upstream source, and available license/guideline metadata. Collection license notices are retained beside this file.

Upstream projects: [Simple Icons](https://github.com/simple-icons/simple-icons), [Devicon](https://github.com/devicons/devicon).
